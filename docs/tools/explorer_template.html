A RISC-V microcontroller the size of a grain of salt

TinyPulse is a 32-bit computer in 0.076 mm² of silicon. It runs C code from flash, talks over a serial port, and has instructions that timestamp pin edges and fire pulses on an exact clock tick.

How it adds, four bits at a time

Most chips add all 32 bits at once. TinyPulse uses one 4-bit adder eight times and holds the carry in a flip-flop between clocks. That makes its register file half the size of a conventional one, which is the difference between a 280 € chip and a 560 € one. Try your own numbers.

The instructions it understands

The full RV32E base set, so an ordinary RISC-V compiler targets it, plus eleven Xpulse instructions for time. Pick one to see its 32-bit encoding.

Running your first program

  1. Plug in the QSPI Pmod

    Attach the Tiny Tapeout QSPI Pmod to the demo board's bidirectional header. It holds your program (16 MB flash) and your data (16 MB RAM). No setup script: the chip wakes both memory chips into their fast modes itself, two microseconds after every reset.

  2. Load your program

    Three ways. Through the demo board's own USB-C port with sw/demoboard/tpboot.py, no extra hardware. At full speed through a USB serial adapter with sw/tpload.py. Or permanently into flash with the Tiny Tapeout Flasher. The first two run your program from RAM until power-off, a quick development loop.

  3. Select the design and release reset

    The heartbeat on uo[7] starts blinking and your code runs from address 0.

  4. Read its output

    The serial port sits on the pins wired to the demo board's RP2040, at 115,200 baud.

#include "tinypulse.h"
#define PERIPH ((volatile uint32_t *)0x30000000)

void uart_putc(char c) { while (PERIPH[4] & 1); PERIPH[3] = c; }

int main(void) {
    PERIPH[2] = 0x10;                     // keep only UART TX on its function
    for (const char *s = "Hi TinyPulse\n"; *s; s++) uart_putc(*s);
    uint32_t t = tp_time() + 50000000;    // one second from now
    tp_arm(t, 0);                         // TRIG0 fires on exactly that tick
    tp_wait(t);
    return 0;
}
